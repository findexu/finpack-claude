finpack-claude

Lean, token-efficient agents and skills for daily Claude Code development.

finpack-claude is a .claude/ kit and plugin marketplace for Claude Code: 9 model-tiered review and design agents, workflow skills, modular rules, and safety hooks — opinionated defaults, all overridable. Install the whole kit in one step, or pick individual plugins.

Install

Recommended — marketplace:

/plugin marketplace add findexu/finpack-claude
/plugin install setup-finpack@finpack-claude
/setup-finpack          # run inside your project

Want just one piece? /plugin install <name>@finpack-claude.

quest-system quickstart

Persistent project memory across sessions — everything learned is written to plain markdown under .ai-context/, so the next chat starts ahead, not from zero. Run /install-quest-system once per project, then:

  1. /new-quest — open a quest (an epic) and its scrolls
  2. /counsel-quest — explore the codebase, settle the battle plan
  3. /embark — start a work session (an expedition)
  4. /make-camp — checkpoint progress and learnings mid-quest
  5. /complete-quest — distill what was learned, archive the quest

Prefer autonomy? /set-bounty "<goal>" lets a party explore, plan, build, self-test, and review, then present a near-done solution for sign-off.
